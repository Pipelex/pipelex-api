# Pipelex API — moved

This repository is archived. The Pipelex API server now lives in the `api/` member of [Pipelex/pipelex](https://github.com/Pipelex/pipelex/tree/main/api), and every pipelex release publishes it under the same version.

- **PyPI:** [`pipelex-api`](https://pypi.org/project/pipelex-api/), import package `pipelex_api`
- **Docker Hub:** [`pipelex/pipelex-api`](https://hub.docker.com/r/pipelex/pipelex-api)
- **Documentation:** [docs.pipelex.com/latest/api-server](https://docs.pipelex.com/latest/api-server/)

The last release from this repository was v0.33.2. Issues and pull requests go to [Pipelex/pipelex](https://github.com/Pipelex/pipelex).
