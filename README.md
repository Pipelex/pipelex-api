# Moved: the Pipelex API Server documentation

This branch used to publish the pipelex-api documentation at https://pipelex.github.io/pipelex-api/. The API server now ships from the pipelex repository, in lockstep with the `pipelex` package, and its documentation is the API Server section of the Pipelex documentation: https://docs.pipelex.com/latest/api-server/

Every page of the old site is now a redirect stub pointing at its counterpart there, and `404.html` sends any other old URL to the API Server overview. The pipelex-api repository is archived.
